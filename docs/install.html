Install

Two paths: grab the macOS app, or run from source. Either way your notes live in ~/devnote as plain Markdown.

On this page · macOS app · From source · Verify · Troubleshooting

macOS app

1
Download the latest .dmg from Releases.
2
Open the .dmg, drag DevNote into /Applications.
3
Launch. Your notes live in ~/devnote — back it up or git-sync it whenever you like.
Unsigned build: the app isn't code-signed yet, so macOS warns on first launch. Right-click DevNote → Open (once). Or Terminal: xattr -cr /Applications/DevNote.app. Windows SmartScreen: More info → Run anyway.

From source

Requires Node 20+, pnpm 9, and (for the desktop shell) a stable Rust toolchain.

git clone https://github.com/shubhscode/devnote.git
cd devnote
pnpm install

pnpm dev                                   # web app on :5173
pnpm --filter @devnote/desktop dev         # desktop app (real Cmd keys)
pnpm desktop:install                       # release build → /Applications + smoke test

Verify

pnpm lint && pnpm test && pnpm e2e && pnpm build
Green means: types + tests + e2e + production build all pass. CI runs the same on every push.

Troubleshooting

SymptomFix
pnpm dev port busyVite defaults to :5173 — kill the other process or run pnpm --filter @devnote/web dev -- --port 5174.
Desktop window blankEnsure pnpm dev (web) is running first; the Tauri shell loads apps/web.
macOS “damaged” warningUnsigned build — use right-click → Open once, or xattr -cr as above.
