Why devnote

Local-first

Notes live as Markdown files in ~/devnote. SQLite is an index, not lock-in. Works fully offline, no account wall.

Code-friendly editor

CodeMirror 6 with GFM preview, syntax highlighting, copy-code buttons, slash menu, table assist, side-by-side and distraction-free modes.

Fast search

Qualifier grammar (book:, tag:, status:, title:, body:) over 5k notes in ~1–3ms. See the search reference.

Telescope

Fuzzy finder on mod K: commands, notebooks, tags, headings, themes — everything keyboard-driven.

Templates & revisions

Built-in templates with placeholders, plus automatic revision snapshots with undoable restore.

Git sync, optional

Share ~/devnote through a private repo. Offline-first by construction, conflicts never drop text. Setup →
