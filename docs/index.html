● Why devnote

Everything you need.
Nothing phoning home.

Built for developers who live in Markdown and the keyboard. Local-first by construction — sync is an adapter, not a requirement.

⚡

Instant search, offline

Qualifier grammar (book: tag: status: title: body:, phrases, -exclusions) over 5k notes in ~1–3ms. Search reference →

🔭

Telescope fuzzy finder

⌘K jumps to commands, notebooks, tags, headings, themes. Prefixes > b t # h.

📝

Code-first GFM editor

CodeMirror 6 + sanitized preview, syntax highlight, copy-code buttons, slash menu, table assist, side-by-side & distraction-free.

🌿

Git sync — optional, yours

~/devnote is plain Markdown with frontmatter. Point at a private repo and sync: export → commit → pull → push. Newer updatedAt wins; losers preserved as .conflict-<device>.md. Airplane-mode fully usable. Setup in 3 steps →

🕘

Revisions & templates

Auto-snapshots on idle + note-switch with undoable restore. 6 built-in templates with date/UUID placeholders on ⌘T.

🎨

7 themes, light + dark

Nord, Dracula, Solarized, Catppuccin + system-follow. Code colors ride the same variables in editor and preview.

⌨️

Keyboard-first

Every action is a core:* command with a remappable shortcut. Full map on the shortcuts page →

🔒

Private by default

No account, no telemetry, zero required network calls. SQLite is an index — Markdown files are the truth.

● Search

Find anything in milliseconds.

One query language across the whole library. Terms combine with AND; rank is title ×3, tags ×2, body ×1.

typescript tag:Work status:Completed
book:Engineering "conflict drill" -draft
title:deploy body:TODO tag:rust
$ pnpm bench

✓ search 5k notes — mean 1.8ms, p99 3.5ms
  gate: <50ms … PASS
Ranking

Pinned notes first, then score, then most recently updated. Matching lines shown as snippets; list renders 200 rows, virtualized beyond.

"exact phrase" matches verbatim. -term excludes. One honest limitation: no partial-match stemming — trin won't find string. Full grammar →

● Get started

Running in under a minute.

macOS app
1
Download the .dmg from Releases, drag DevNote into /Applications.
2
First launch: right-click → Open (unsigned build), or xattr -cr /Applications/DevNote.app.
3
Notes land in ~/devnote. Optional: add a private repo in Preferences → Git sync. Full guide →
From source
git clone https://github.com/shubhscode/devnote.git
cd devnote
pnpm install
pnpm dev        # web on :5173
pnpm lint && pnpm test && pnpm build
