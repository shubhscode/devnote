# ADR-001: Tauri 2 + Web SQLite fallback

Date: 2026-09-12. Status: accepted (pending rustup install).

## Decision

- Desktop: **Tauri 2** (Rust backend: fs, SQLite FTS5 via `tauri-plugin-sql`, opener/dialogs). Web app (`apps/web`) loads in WebView.
- Web persistence until desktop lands: in-memory + localStorage stub, then `wa-sqlite` + OPFS (or Dexie if SQLite proves heavy).
- Sync (Phase 3): PouchDB ↔ CouchDB protocol, local-first.

## Alternatives rejected

- Electron: heavier bundle, larger attack surface, no Rust backend leverage.
- Pure Rust UI (egui/iced/GPUI-style like Zed): 10x work for markdown preview/themes; wrong tradeoff for a notes app.

## Consequences

- Requires rustup + Tauri CLI for `apps/desktop`. `pnpm dev/build/test` must stay green without Rust.
- Icons: `reicon-react` (MIT) — named imports, Outline default, Filled where emphasis needed.
