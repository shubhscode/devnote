Preferences and themes

Open Preferences with mod , or the sidebar gear. Settings persist locally; theme and code colors stay coordinated across the editor and preview.

Applies to v0.3+Web and desktopSettings stay local
On this page · General · Appearance · Editing · Panes · Shortcuts tab

General

Default notebook controls where notes created from All Notes land. Auto uses the first available notebook. Sync, backup, and restore live on the separate Sync tab documented under sync, files, and backup.

Appearance

devnote ships nine coordinated appearances: Light, Dark, System, Catppuccin Latte, Catppuccin Mocha, Solarized Light, Solarized Dark, Dracula, and Nord. System follows the operating system. Code colors use the same theme variables in both the editor and preview.

Switch without opening Preferences through Telescope: press mod K, type h, choose a theme, press Enter.

Editing

  • Word wrap: toggle soft wrapping in the Markdown source.
  • Editor font size: 11–18 px slider; headings and code scale with it.
  • Note list order: default order when no search query is active. Search always ranks by relevance.
  • Formatting remains in the selection bubble menu; / inserts blocks, and mod F finds within the note.

Panes

Collapse the sidebar with mod / and the note list with mod \. The note-list toggle lives at the top-left of the editor pane and switches between fullscreen and exit-fullscreen icons. Drag pane dividers to resize; double-click a divider to reset. Widths persist locally.

Shortcuts tab

The Shortcuts tab is currently a filterable reference for every core:* command and default binding. It also shows command IDs for unbound actions. Full key remapping is planned with the later plugin/keybinding work; for now, run any command from Telescope’s > source.
