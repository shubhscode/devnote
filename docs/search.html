Search reference

One query language across the whole library. Focus with mod ⇧ F, clear with esc. The filter icon scopes to the current notebook; the globe searches everything.

Applies to v0.3+Web and desktopOffline
On this page · Grammar · Scope · Combining terms · Ranking · Limitations

book:WorkNotes in the Work notebookbook:Engineering rust

Scope

Notebook-only scope filters the current notebook; global scope searches all notebooks. Trash scope is fixed to Trash. For command-style jumping instead of filtering, use Telescope.

Combining terms

Terms combine with AND:

typescript tag:Work status:Completed
book:Engineering "conflict drill" -draft
Exclusions-only matches nothing. A query of only -draft returns no results by design — add at least one positive term.

Ranking

Title hits ×3, tag hits ×2, body hits ×1. Pinned notes sort first, then score, then most recently updated. Matching lines appear as snippets under each result.

$ pnpm bench
✓ search 5k notes — mean 1.8ms, p99 3.5ms (gate <50ms)

Limitations

No partial-match stemming: searching trin won't find string. This is deliberate for predictability at 5k-note scale — FTS5 ranking parity is tracked in the roadmap.
