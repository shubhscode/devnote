Search reference

SyntaxMatches
book:WorkNotes in the Work notebook
tag:rustNotes tagged rust
status:activeNotes with status active (none active onHold completed dropped)
title:deployTitle contains deploy
body:TODOBody contains TODO
"exact phrase"Quoted phrase match
-draftExcludes notes containing draft

Terms combine with AND: typescript tag:Work status:Completed. Ranking: title ×3, tags ×2, body ×1; pinned notes first, then score, then most recently updated.

There is no partial-match stemming: searching trin won't find string. An exclusions-only query matches nothing.

Focus search with mod shift F, clear with esc. The filter icon scopes to the current notebook, the globe searches all notebooks.
