Telescope

Press mod K anywhere and fuzzy-find commands, notebooks, tags, headings, tasks, and themes. Matches highlight as you type.

Applies to v0.3+Web and desktopKeyboard-first
On this page · Scopes · Keys · Workflows

Scopes

PrefixSearchesExamples
>core:* commands> sync, > theme
bNotebooks by pathb Projects
tTags with countst rust
#Headings and tasks in the open note# deploy
hThemesh nord

Type a prefix plus a space to scope the search: b Projects. Symbol prefixes may also attach directly: >sync and #deploy. Without a scoped prefix, Telescope searches all sources and shows the best matches per group.

Workflows

  • Commands: mod K, type >, run sync, export, history, theme, or navigation commands.
  • Move quickly: mod K, type b Projects, press Enter to open or ⇧ Enter to move the active note there.
  • Tag quickly: mod K, type t rust, press Enter to filter or ⇧ Enter to add the tag.
  • Jump inside a note: mod K, type # deploy, press Enter to jump to the heading or task.
  • Change appearance: mod K, type h nord, press Enter.
