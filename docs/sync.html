Sync (optional, git-based)

Sync is never required. Everything works with Wi-Fi off. When you want a second machine (or a backup with history), share ~/devnote through a private git repo.

Setup

  1. Create a private repo (e.g. git@github.com:you/devnote.git).
  2. In devnote: Preferences → General → Git sync, paste the remote URL.
  3. Click Sync now — initializes the repo, exports notes, commits, pushes.

How it works

  • Each note is one .md file with YAML frontmatter: ~/devnote/<notebook-path>/<slug>-<id8>.md.
  • Sync now = export → commit → pull → resolve conflicts → push → import.
  • Status dot in the sidebar: green = synced, yellow = uncommitted, blue = unpushed, red = conflict.
  • Manual trigger only — you control when to sync.

Conflicts

Per-file granularity. Newer updatedAt wins; the loser is preserved as <name>.conflict-<device>.md plus a banner. Text is never silently dropped.

Deleting a note sets trashed: true in frontmatter (a tombstone), so deletes propagate without resurrecting files.

Backup

Preferences → General → Backup & restore → Export backup (.zip). Restore overwrites ~/devnote from a zip.
