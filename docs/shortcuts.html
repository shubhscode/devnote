Use a space after letter prefixes (b Projects); symbol prefixes may attach directly (>sync, #deploy). Esc steps back through filter, scope, all sources, then close. Full workflows are on the Telescope page.

Remapping

Reference today, remapping later: Preferences → Shortcuts filters the canonical command list, but does not yet edit bindings. Run any command from Telescope. Full key remapping is planned alongside the plugin API.
